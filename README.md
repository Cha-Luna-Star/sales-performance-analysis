# Sales Performance Analysis

This repository contains a sales performance analysis project using a sample retail dataset. The goal is to analyze sales trends, customer behavior, product performance, and regional profitability.

## Project Structure

- `data/` - Raw dataset files
- `sql/` - SQL schema and analysis queries
- `notebooks/` - Jupyter notebooks for exploratory analysis
- `powerbi/` - Power BI dashboard files
- `screenshots/` - Dashboard screenshots
- `README.md` - Project overview
- `requirements.txt` - Python dependencies

## Dataset

The dataset used in this project is a sample retail dataset from the Superstore sales dataset.

## Tools

- Python
- SQL
- Jupyter Notebook
- Power BI
- Pandas / NumPy / Matplotlib / Seaborn

## Business Questions

- Which regions generate the most revenue?
- Which products have the highest sales and profit margins?
- What is the monthly sales trend?
- Which segments perform best?
- Which categories have low profitability?
- How do discount rates affect sales and profit?

## Getting Started

1. Clone the repository.
2. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```
3. Explore the sample data in the `data/` folder.
4. Use SQL queries in `sql/analysis_queries.sql`.
5. Run the notebook in `notebooks/sales_analysis.ipynb`.
